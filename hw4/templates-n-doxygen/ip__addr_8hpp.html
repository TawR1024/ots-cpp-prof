◆ print_ip_ce()

template<typename IP >
void print_ip_ce ( IP  ip_addr)

Prints the given value as an IP address followed by a newline.

The output format depends on the argument type:

  • std::string is printed as is;
  • integral types are decomposed into bytes, most significant byte first, with octets separated by dots;
  • other container-like types are printed element by element, separated by dots.
Параметры шаблона
IPThe type of the value to print.
Аргументы
ip_addrThe value to print.
